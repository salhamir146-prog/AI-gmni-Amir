# ChatGPT Classic — Gemini Edition

بازطراحی حرفه‌ای رابط کاربری چت (تم روشن/تیره، دقیقاً شبیه ChatGPT) با پشتیبانی واقعی از سوییچ بین چند دسته مدل Gemini، از طریق Cloudflare Pages Functions.

## ✨ امکانات نسخه جدید

- **سوییچ واقعی بین مدل‌ها**: هر مدلی که در تنظیمات انتخاب و ذخیره شود، دقیقاً همان مدل در درخواست بعدی به API ارسال می‌شود.
- **تولید و نمایش تصویر**: مدل‌های تصویری Gemini (`*-image`, «Nano Banana») و مدل‌های Imagen (`imagen-4.0-*`) هر دو پشتیبانی می‌شوند و تصویر تولیدشده مستقیم در چت نمایش داده می‌شود.
- **تبدیل متن به گفتار (TTS)**: مدل‌های `*-tts` صدا تولید می‌کنند و به‌صورت فایل WAV قابل پخش در چت نمایش داده می‌شوند (نام صدا از تنظیمات قابل تغییر است).
- **تولید ویدیو (Veo)**: با الگوی غیرهمزمان (شروع + polling)، وضعیت تولید در چت نمایش داده می‌شود.
- **پنل تنظیمات چندبخشی**: مدل / پارامترها (دما، Top-P، حداکثر توکن، صدا، نسبت تصویر) / دستورالعمل سیستم / راهنمای امنیتی.
- **پوسته روشن و تیره** با انیمیشن‌های ظریف (ورود پیام، تایپینگ، مودال، توست).
- **کپی پاسخ و کپی کدبلاک‌ها**، پاک‌سازی HTML خروجی مدل با DOMPurify.
- **تست اتصال** به API از داخل تنظیمات.

## 🧠 حافظه بلندمدت (جدید)

برنامه حالا یک حافظه بلندمدت واقعی دارد که با **Cloudflare KV** ذخیره می‌شود:

- بعد از هر پاسخ متنی، یک درخواست پس‌زمینه (fire-and-forget) با مدل `gemini-flash-latest` نکات پایدار درباره کاربر (نام، علایق، شغل، پروژه‌های در حال انجام و ...) را از گفتگو استخراج و با حافظه قبلی ادغام می‌کند.
- این حافظه در ابتدای هر درخواست بعدی، به‌صورت خودکار به `systemInstruction` اضافه می‌شود تا مدل «کاربر را به‌خاطر بسپارد».
- هر مرورگر یک شناسه یکتا (`clientId`) در `localStorage` می‌سازد که کلید ذخیره‌سازی در KV است — یعنی حافظه بین گفتگوهای مختلف همان مرورگر مشترک است.
- از تنظیمات → تب **حافظه** می‌توانید حافظه فعلی را ببینید، آن را غیرفعال کنید، یا با دکمه **«حذف حافظه»** کاملاً پاکش کنید (این کار داده را از KV هم پاک می‌کند و برگشت‌ناپذیر است).

## 📁 ساختار فایل‌ها

```
index.html
style.css
app.js
functions/api/chat.js     ← متن + تصویر Gemini + TTS (generateContent)
functions/api/imagen.js   ← تصویر Imagen (predict)
functions/api/video.js    ← ویدیو Veo (predictLongRunning + polling)
functions/api/memory.js   ← حافظه بلندمدت (Cloudflare KV)
README.md
```

## 🚀 راه‌اندازی

1. یک ریپازیتوری جدید در GitHub بسازید و تمام فایل‌های بالا را با همین ساختار پوشه‌ای (از جمله پوشه `functions/api/`) در آن قرار دهید.
2. در **Cloudflare Pages** یک پروژه جدید بسازید و ریپازیتوری را متصل کنید (Build command خالی، Output directory = `/`).
3. در `Settings → Environment Variables` متغیر `GEMINI_API_KEY` را با کلید API جمنی خود اضافه کنید.
4. **ساخت KV Namespace برای حافظه بلندمدت:**
   - در داشبورد Cloudflare برو به `Workers & Pages → KV`.
   - روی **Create a namespace** بزن، یک اسم دلخواه بده (مثلاً `chat-memory`) و بساز.
   - برگرد به پروژه Pages‌ات → `Settings → Bindings` (یا `Functions → KV namespace bindings`).
   - یک Binding جدید اضافه کن با **Variable name** دقیقاً `USER_MEMORY` و namespace‌ای که ساختی رو انتخاب کن. این کار را هم برای Production و هم Preview انجام بده.
5. یک بار دیگر Deploy/Retry بزن تا Binding اعمال بشه.

> اگر KV را وصل نکنی، بقیه برنامه (چت، تصویر، صدا، ویدیو) عادی کار می‌کند؛ فقط تب «حافظه» خطای «KV متصل نشده» نشان می‌دهد و حافظه ذخیره نمی‌شود.

## ⚠️ نکات مهم فنی

- ساختار درخواست‌های متن و تصویر Gemini (`generateContent` + `responseModalities`) و TTS (`speechConfig.voiceConfig.prebuiltVoiceConfig`) بر اساس مستندات و نمونه‌کدهای رسمی گوگل پیاده‌سازی شده‌اند.
- برای مدل‌های **Imagen** و **Veo**، از الگوی استاندارد `predict` و `predictLongRunning` استفاده شده، اما چون نام دقیق برخی مدل‌ها و پارامترهای آن‌ها ممکن است بین نسخه‌های API تغییر کند، پیشنهاد می‌شود قبل از استفاده جدی، پاسخ خطا (در صورت وجود) را در کنسول مرورگر بررسی و در صورت نیاز نام مدل/پارامترها را با مستندات فعلی `ai.google.dev` تطبیق دهید.
- مدل‌های **Lyria (موسیقی)**، **Embedding**، **Robotics**، **Agent** و **Computer-Use** برای گفتگوی متنی ساخته نشده‌اند و در این نسخه پیام راهنما نمایش می‌دهند، نه خطای خام.
- کلید API فقط در Cloudflare Environment Variables ذخیره می‌شود و هیچ‌گاه در کد سمت مرورگر ظاهر نمی‌شود.
