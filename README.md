# ChatGPT Classic - Light Theme (Gemini Backend)

پروژه بازطراحی‌شده رابط کاربری **ChatGPT تم سفید (Light Theme)** متصل به انواع مدل‌های Gemini از طریق **Cloudflare Pages**.

## 📁 ساختار فایل‌ها:
- `index.html`: ساختار اصلی صفحه و منوها
- `style.css`: استایل دقیق تم روشن چت‌جی‌پیتی
- `app.js`: منطق برنامه و ارتباط با API
- `functions/api/chat.js`: بک‌اند سرورلس کلودفلر جهت امنیت کلید API
- `README.md`: راهنما

## 🚀 راهنمای ساخت ریپازیتوری گیت‌هاب و اتصال به کلودفلر:

1. یک ریپازیتوری (Repository) جدید در گیت‌هاب بسازید.
2. ۵ فایل بالا را دقیقاً با همین ساختار درون آن آپلود کنید.
3. در **Cloudflare Pages** پروژه جدید بسازید و ریپازیتوری گیت‌هاب را وصل کنید.
4. در تنظیمات پروژه کلودفلر (`Settings` > `Environment Variables`):
   - متغیر جدید به نام `GEMINI_API_KEY` ایجاد کنید و کلید API جمنی خود را در آن قرار دهید.
5. دکمه Deploy را بزنید!
